## How to run

1. Set a recurring reminder in your own calendar or task tool for each review frequency: monthly for the fee rows, quarterly for licence and guidance rows, annually for static standards and archived documents. Nothing in this file creates a schedule.
2. At each review, open each URL in the table, read the "Reviewed on" or "Last updated" date, and compare it with the value recorded here.
3. If the date has moved, check the lesson files listed under "Dependent lessons or licence rows" and update their wording, fees or links there. Record the new date in this table.
4. Rows marked "Not fetched" or "Blocked" need a manual check in a browser, because the automated check could not read them.
5. Redirects and www/non-www pairs are listed separately; check both when either appears.
