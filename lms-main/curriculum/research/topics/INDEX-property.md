## 3. Cross-cutting findings

1. Victoria is not the default. The matrix covers VIC, NSW, QLD, WA, SA, TAS, ACT and NT. Only the states listed in each brief have rows; the rest are marked UNCONFIRMED or NOT RESEARCHED.
2. NSW and QLD rows in `LICENCE-MATRIX.csv` are superseded by `LICENCE-MATRIX-NSW-QLD.csv` (per the NSW-QLD notes). This index uses the newer IDs.
3. Property management licensing is the main legal risk in this batch (`portfolio.md`, `property-manager-partner.md`). Victoria and Queensland have licence routes that appear to cover managing rentals for others, but the wording is PARTIAL. NSW is UNCONFIRMED. Lessons must not teach or imply unlicensed letting or managing.
4. NSW pesticide rules may apply to garden and lawn herbicide use for a fee. The pest management technician page is silent on herbicides; the ground applicator fact sheet excludes gardens and lawns (amenity horticulture). The position is UNCONFIRMED. Lessons should not state it either way.
5. Several QBCC pages in the matrices show 2021 review dates alongside 2026 fee notes. Treat those scope texts as possibly out of date (painting, plastering, tiling, pool, handyman, fence).
6. Standards: the editions named for AS 3958.1 (2007), AS 3500.1 (2018 or 2021), AS/NZS 3760 (edition unconfirmed) and the ADG Code (edition unconfirmed) need checking against Standards Australia before any lesson cites them.
7. Pool chemical dosing, storage and target water-chemistry values are not confirmed in any state. No numbers are given in the briefs.
8. Spa Legionella duties are not checked. Do not write spa lessons that state Legionella requirements until a source is read.
9. Catalogue gaps: `planning/CATALOGUE-V2.csv` records no source lessons for lawn, landscaping, irrigation, pond, aquarium, locksmith, deck, flat-pack and handyman's new trade lessons. These are NEW. The briefs treat them as new.
10. Biosecurity: fire ant movement rules cover soil, mulch, turf and potted plants in Queensland and NSW zones. Garden waste and landscaping material are not named on the page read; UNCONFIRMED.
11. Asbestos thresholds differ by state (for example Queensland and Tasmania 10 m2; Victoria 10 m2 and one hour in seven days for unlicensed removal). Lessons must quote them only with the state's source.

## 4. Decisions made in this pass (for review)

1. Course slugs follow `structure/COURSES-MODULES.json` (for example `pool`, `pond`, `flatpack`, `portfolio`, `deck`, `locksmith`).
2. `property-manager-partner` is a proposed slug for a module that has no slug in the structure file.
3. The brief for each course uses the state rows from the matrix files as they are; no status has been upgraded.
4. The NSW and QLD matrix rows replace the older rows in `LICENCE-MATRIX.csv` for this index.
5. Where a source named a standard but the text was not read, the standard is shown as LISTED or UNCONFIRMED, not as confirmed.
6. The ACCC toppling furniture standard is recorded as a supplier duty; lessons should describe installer anchoring as the supplier's instruction and good practice.
7. Mould-related content is referenced only as DECISIONS.md states (kept in pressure-cleaning and property-maintenance content with warnings). It is not added to this batch's scope.
