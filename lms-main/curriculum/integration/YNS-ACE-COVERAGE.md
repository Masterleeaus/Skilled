# YNS and ACE coverage table

Status key: **new** = new lesson written in this pass; **covered by** = the content already exists in the named lesson, so it is not repeated; **used in** = content used inside a new lesson; **not used** = reason given. Source section names are paraphrased here, so this table does not reproduce the source's headings.

Rights for both sources: user-held; reworded (no copying). Copy check run with overlap.py against each source in turn: zero runs of four or more words in YNS-01 to YNS-04 or ACE-01 to ACE-04, including the assessment files.

Dating: the Yoga Niche Secrets workbook is a 2017 marketing webinar. The ACE chapter is from a US manual (4th edition). Neither is dated for Australia. Any figure from either is marked as US or historical, or is not used.
