## Decisions (for reviewer)

1. The ADA source is Australian (Australian Dental Association, 2015). It is used as an Australian dental source. The US-legal exclusion in the brief does not apply; Australian legal and standards references are marked UNCONFIRMED instead.
2. `lessonType` is `K` for all 14 lessons. `RH` was not used because the only definition found in the curriculum for `RH` is "revenue, higher hourly rate".
3. `courseSlugs` use canonical slugs only: `healthcare` for all; `medequip` added where the lesson covers equipment (ADA-02, ADA-03, DIP-02, DIP-03); `postcon` added to HIP-03 (building work). HCG lessons use the folder name `healthcare-cleaning` in their list files. That is not a canonical slug and was not copied.
4. Layer `high-risk` is used where a lesson includes a disinfectant application, a sharps step, or a waste step. Otherwise `group`.
5. Overlap with existing HCG lessons was resolved by marking topics COVERED rather than writing duplicate lessons. Only topics with no HCG equivalent became new lessons.
6. Module titles were taken from the `healthcare` course module list in `COURSES-MODULES.json`: "Safety and hazards" and "Methods and technique". The HCG-LIST uses "Quality, evidence and handover", which is not in the healthcare module list; not changed here.
7. Dosing, concentrations, flush durations, mop frequencies, transmission percentages and vaccine schedules are not copied from any source.
8. Learner files contain no `correctIndex`. Answer keys and rationales are in `curriculum/assessments/<ID>.assessment.json`.
9. The DIP source text is OCR output. Figures and wording taken from it are flagged for a check against the scan.
