## Observations (not counted as flow failures)

- Login on `http://127.0.0.1:3000` fails with CORS errors. The API allows `CLIENT_URL=http://localhost:3000`, so the run used `localhost`. This is a local setup detail, not a defect on main.
- Redis: `REDIS_URL` must not contain credentials. The password goes in `REDIS_PASSWORD`. The `.env.example` template uses the same key names, so this is only a local configuration note.
- On the login page the frontend calls `POST /api/auth/refresh` before any login and receives HTTP 422. It appears as a browser console error. Its cause was not investigated here.
- Academy content (lessons, practical revisions, answer keys) cannot be published on a fresh database. Unblocking F11, F12, F16, F17 and F18 needs seeded, approved academy content, which this run did not have.
