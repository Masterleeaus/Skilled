## Decisions for review

1. **Scope.** The source is a 2012 NSW hospital cleaning procedure set, not a green cleaning manual. It has almost no green content. The batch therefore produces 3 lessons, not a full green module. The green and sustainability lessons already exist in the F13 series (F13-L01 to F13-L05), and this batch does not duplicate them.
2. **Not written as separate lessons.** Hospital patient-room method (row 7) belongs to the healthcare material. Dosing (rows 12 and 18), hand hygiene (rows 15 and 23 and 27), manual handling (row 11), chopping-board storage (covered in GCM-03), and the microfibre folding rule (row 5) are covered by existing lessons or carried into GCM-02.
3. **GCM-03 layer.** Set to `high-risk` because the sanitising step is a chemical-hazard step. The `High-risk cleaning` module exists only in the high-risk course, so GCM-03 uses `Group (Cleaning & Hygiene): Safety and hazards` instead. Confirm this placement.
4. **GCM-02 courses.** Strata is excluded because the strata course has no `Equipment and materials` module.
5. **Course slugs.** The folder names in `courses/` are used, as the brief asks. `structure/COURSES-MODULES.json` uses different slugs (`residential`, `commercial`, `bond`, `shortstay`, `strata`). That file was not touched, so the mismatch remains for the owner to resolve.
6. **lessonType.** `K` for all three. No revenue or cost lesson fits this source.
7. **Business fields.** Only fields from `business-lesson-fields.json` are used: `procedures.quality_standard`, `quality.inspection_checklist`, `quality.evidence_requirements`, `equipment.assigned_items`, `equipment.inspection_checklist`, `materials.approved_products`, `materials.storage_procedure`, `safety.required_ppe`.
8. **No external checks.** No web or regulator sources were checked for this draft. Every point that depends on current law, standards or product labels is marked UNCONFIRMED.
9. **Not added to the schema.** ECO-03 carries a `buildNotes` field. It is not in SCHEMA.md, so this batch does not use it. The overlap notes are in this file.
