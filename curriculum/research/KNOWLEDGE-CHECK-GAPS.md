## Decisions made without asking

1. One replacement check per gap lesson, as requested. Seven lessons had one check before and now have two, so they remain below 3 (listed below).
2. Each new check uses a fact stated in that lesson's own text. The source section and sentence are in the table. Where a lesson states a figure or rule from an outside source, the check repeats the lesson's wording and does not add any new fact.
3. Check IDs continue the lesson's existing numbering (`<lesson-id>-K<nn>`). Where a dropped check had the highest number, its ID is reused, because the dropped key was removed.
4. Correct options are placed at varied positions (0 to 3). Options are 4 each, with exactly one correct option.
5. Where a learning outcome had no good fit (for example NEW-LCK-04 on secure storage of key records, or SOL-01 on values), the check covers the nearest sourced fact, and the table says so.
6. Status stays DRAFT and reviewStatus stays NOT REVIEWED. No check is marked verified.
7. Insertions were made by exact-string insertion after each array's last element. Each file was re-read immediately before editing. Other fields and formatting were left as they were.
