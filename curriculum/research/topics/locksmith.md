## 1. Scope and boundaries

In scope:
- Lock change, rekey, repair and replacement for residential doors (within the licence rules in section 5).
- Key cutting, where state rules allow it (QLD retail key cutting is exempt, per matrix).
- Installation of door hardware: strike plates, closers, security screen door hardware (where licence rules allow).
- Door installation and hanging, subject to the carpentry rules in section 5 (state rules UNCONFIRMED in several states).
- Key control, key registers, and client identity checks.

Out of scope or referred:
- Alarms, CCTV and other security systems (security equipment installer licence in QLD; WA Class 1 and Class 4 security installer; VIC security equipment installer activity, per matrix).
- Electric locks, wiring and access control with electrical connections (licensed electrician).
- Fire doors and fire-rated door sets (refer to the building surveyor or a qualified specialist; standard UNCONFIRMED).
- Opening vehicles or doors for people without verified authority (out of scope; UNCONFIRMED rules per state).
- Structural frame repairs (carpentry or building licence rules; state position UNCONFIRMED).

## 2. Key technical methods

- Lock identification: mechanism type (pin tumbler, lever, cylinder, mortise), operating side, and door thickness before ordering parts.
- Security grade selection: match the lock to the door and the risk, using the lock standard named below.
- Rekeying: remove the cylinder; change pins or core per manufacturer method; test with all keys; record the key codes and who holds each key.
- Fitting: align the strike and latch; check the door closes without force; test the deadbolt throw.
- Door hanging: plumb, level, and fixings in the frame; check the door's clearance and seal.
- Key control: a register of keys issued, to whom, when, and the verification used.
- Client identity: verify the person's authority before any lock change; record the check. The method is a process point; state rules UNCONFIRMED.
- Records: job sheet, parts, key codes (access controlled), photos where allowed, and client sign-off.

## 4. Main hazards

- Cuts and hand-tool injuries, drill and cutter hazards.
- Manual handling of heavy doors and frames.
- Ladders for high doors and frame work.
- Electric shock when drilling into walls with cables.
- Traffic and roadside risk at lockout jobs.
- Injury from sudden door movement during hanging.
- Data and personal information risk: client identity records, key codes, and addresses (privacy point; the OAIC page applies).
- Security risk to the client: keys and codes left unsecured.
- Asbestos or lead in old frames or paint (see `handyman.md` section 5).

## 5. Regulator references and licence facts

NSW:
- [NSW-10, CONFIRMED] Individual locksmith: Class 2C licence under the NSW Police SLED scheme. Page states locksmiths must hold a Class 2C licence to work in the security industry (FAQ, undated in this pass).
- [NSW-11, UNCONFIRMED] Locksmith company (master licence): the NSW Police PDF refers to the master security licence number for licensed security businesses; it does not say whether a locksmith company must hold a master licence or which class. PDF is undated.
- [NSW-04, PARTIAL] Carpentry contractor licence over $5,000 (labour and materials). Door installation is not named in that row; whether it is carpentry is UNCONFIRMED.
- [NSW-05, UNCONFIRMED] Minor trade work page is inconsistent (see `handyman.md` section 5).

QLD:
- [QLD-04, CONFIRMED] Locksmith work is generally licensed as a security equipment installer under the Security Providers Act 1993, in most cases. Exempt: retail key cutting; installing basic security items during construction, repair or renovation. Removing and reinstalling household locks needs a licence unless the building is under construction, repair or renovation (QLD apply page updated 21 October 2026).
- [QLD-13, PARTIAL] Carpentry licence class covers timber and metal fences; door installation not named in the matrix row. Door installation status UNCONFIRMED.

VIC:
- [VIC-07, UNCONFIRMED] Private security pages (updated 2 November 2026) describe the Private Security Individual Operator Licence, the Private Security Business Licence and the security equipment installer activity (CCTV, alarms, safes, vaults). Locksmithing and key cutting are not named. Enquire with the Licensing and Regulation Division.
- [VIC-08, UNCONFIRMED] Door installation is not on the BPC exemption list; whether it is carpentry or another exempt trade is not stated. Possible registration for carpentry work over $10,000 is an inference only.

WA:
- [WA-07, PARTIAL] Security installer licence Class 1 (installing, maintaining or repairing safes, vaults and locks) and Class 4. Locksmith is not a licence type on the page; it appears as a Class 1 qualification. Key cutting not mentioned.
- [WA-08, UNCONFIRMED] Door installation not named on the builder registration checklist.

SA:
- [SA-04, UNCONFIRMED] Security agent licence activities named do not include locksmith work.
- [SA-05, UNCONFIRMED] Door installation not addressed.

TAS:
- [TAS-07, UNCONFIRMED] Security and Investigations Agents Act 2002 exists (search result); CBOS page returned a client error.

ACT:
- [ACT-07, UNCONFIRMED] Not among the ten construction occupations in section 7 of the Construction Occupations (Licensing) Act 2004. ACT security licensing not researched in this pass.

NT:
- [NT-08, UNCONFIRMED] Security licence types named: security officer or crowd controller, security firm, and corporation or partnership. Locksmith not named as licensable.

Privacy:
- [OAIC small business page, read; published 10 March 2023, modified 5 Sept 2024] Businesses with annual turnover of $3 million or less are generally exempt from the Privacy Act, but several categories are caught regardless of turnover (health service providers, businesses that trade in personal information, and others). Whether a locksmith business is caught is UNCONFIRMED for each client job.

## 6. Scope points for licence notices

- NSW notice: individual locksmiths need a Class 2C licence under the SLED scheme. The lesson does not grant it. Company licensing is UNCONFIRMED.
- QLD notice: lock work is generally licensed as a security equipment installer; retail key cutting and certain basic installations are exempt; the lesson does not grant a licence.
- VIC notice: do not state a locksmith licence position until confirmed.
- Completing the lesson does not grant a licence in any state.
