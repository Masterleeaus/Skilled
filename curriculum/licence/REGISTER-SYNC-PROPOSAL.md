# Register sync proposal: lesson-licence.json against current learner text (2026-11-03)

Status: proposal only. Nothing in `curriculum/licence/lesson-licence.json` or any lesson file has been changed, committed or staged. Scope: the 87 lessons in `curriculum/research/BOOM-OTHER-STATES.md`, the 10 Victorian asbestos lessons, and the 75 PV-listed files from `PV-WORDING-PROPOSAL.md` and `PV-WORDING-COURSES-PROPOSAL.md` (PVB-02 excluded, because its PV claims were removed). 61 of the PV-listed files are also in the boom group and are covered there.

## Decisions made (review these)

- **D1. Boom rows move from not_checked to threshold.** I applied the rule as given: threshold where the text states a value. The text states the 11 m boom-length WP rule for NSW, QLD, TAS, NT and WA, and for VIC it states that there is no length threshold. The scope pass earlier today (`licence/reclassification-scope.md`) set most of these lessons to not_checked on the view that a boom note is not work the lesson teaches. If that view stands, the 80 status changes in the boom table should stay not_checked and only the states and limit fields should change. This is the largest open decision.
- **D2. Victoria is listed in states with no limit.** The Victorian WP class has no boom-length threshold, so VIC is recorded as a state with the note "no boom-length threshold", not as a limit.
- **D3. WA and NT boom rows.** States are taken from the lesson text, which cites the WA and NT pages checked 2026-11-03 (R90 and R91 in `BOOM-OTHER-STATES.md`). Those page URLs should be added to each entry's officialUrl. TAS is kept as the text states it (WorkSafe Tasmania page, last updated 1 December 2023). BOOM-OTHER-STATES.md does not cover TAS, so I did not re-check it.
- **D4. Cumulative clause is supported, not removed.** `NEW-TIL-05` says in its note that "cumulative across all employees" is not on the Victorian unlicensed-removal page, and it removed the phrase from its entry. A WebFetch of that page (returned as a summary, not a full read) shows the parenthetical "(this period is the cumulative total time the asbestos removal work is carried out by all employees over a period of seven days)". So the note is wrong, the learner text is right, and the register should carry the clause. A person should read the page once to confirm before the entry is changed.
- **D5. The 10-minute asbestos-dust condition is out of the limit.** The page does state a 10-minute dust condition (WebFetch, same as D4). The learner text in `property-maintenance-L05` says the rest of that condition is not confirmed and not to be relied on, so the register should not state it as a limit.
- **D6. roof-cleaning-soft-washing-L05 required to not_checked.** Its own work is to identify and refer, and it does not isolate, test or repair. The VIC installation rule is real and has no threshold, but it covers installation and maintenance, not the roof wash. The 50 V / 120 V line in the register is not in the learner text, so it is removed.
- **D7. handyman-work-L06 required to threshold.** Its NSW basis now carries a value exclusion (50 V AC / 120 V ripple-free DC), so it is not "any value". It is not clear the lesson's own work is licensed, so this is a judgement call.
- **D8. roof-cleaning-soft-washing-L03 threshold to not_checked.** The learner text gives no state value for asbestos or boom length. It points to the asbestos lesson and says the state rules are not confirmed. The register values do not appear in the current learner text.
- **D9. States values for PV lessons.** `VIC (PV rule checked)` reads as if PV cleaning was checked. Text states only the VIC installation and maintenance rule. Entries are reworded to say so. Where the text says nothing about VIC PV (solar L07, L08, L09, L10, L12), the ESV wording is cleared from the entry.
- **D10. HR04 entry added.** There is no entry, and the text states a numeric VIC allowance. The lesson's own work is mould remediation, so this is a threshold.

## Method

Register entries were read from `curriculum/licence/lesson-licence.json` (445 entries). Learner text was read from the lesson JSON files under `curriculum/courses/` and `curriculum/shared/`: instruction, procedure, workedExamples, equipmentAndPpe, commonErrors, safetyAndRegulatory, qualityStandard, documentationEvidence, summary, knowledgeChecks, learningOutcomes, prerequisites and audience. sourceReferences, officialReferences and referencesAtStart were not used as evidence of the learner claim. Sentences were matched by keyword (boom, work platform, WP, 11 m, PV, solar, asbestos, 10 m2, one hour, licence) and checked by hand for the rows above. One WebSearch (domain-limited to asbestos.vic.gov.au) and one WebFetch of the unlicensed-removal page were used (D4, D5). No lesson file, register entry or other repository file was edited, and nothing was committed.
